# ShakerScan 0.8.14

ShakerScan 0.8.14 is a Fleet initialization reliability patch over 0.8.13. It carries forward the
complete 0.8.13 scanner, API, UI, Model Intake, agent/MCP routing, documentation, and private sandbox
queue fixes.

## Fix

- Managed broker Fleet initialization now treats the bundled MinIO bucket initializer as part of
  readiness. The control plane retries the real artifact PUT/GET/DELETE health probe for up to 120
  seconds instead of rolling a valid conversion back when the API becomes healthy a moment before
  the bucket exists.
- The same bounded retry applies to operator-configured external S3 storage and still fails closed
  when the artifact plane never becomes writable.
- A regression covers both the transient HTTP 503 path and a structured not-ready probe before the
  successful write check.

## Validation

The candidate must pass the full backend, CLI, documentation, and UI suites; generated inventory;
named release gates; dependency audits; production builds; clean/dirty upgrade smokes; independent
published-manifest verification; and literal clean installation on the control-plane and worker
VPSs. Remote acceptance additionally verifies managed HTTPS Fleet enrollment, exact-node parallel
DAST execution, worker-loss reclaim, centralized persistence, a bounded Model Intake review, agent
and MCP remote routing, and private sandbox queue ownership.

## Install

After publication and stable-channel promotion:

```bash
curl -fsSL https://install.shakerscan.com | sh
```

The generated launcher pins ordinary operations to `0.8.14` unless the operator explicitly selects
another image tag.

- `shakerscan/shakerscan-scanner:0.8.14`
- `shakerscan/shakerscan-api:0.8.14`

- `shakerscan/shakerscan-model-intake-signer:0.8.14`
- Platforms: `linux/amd64`, `linux/arm64`

## Supported deployment boundary

ShakerScan 0.8.14 remains a trusted-operator, self-hosted release. Localhost is the default; remote
operator access belongs behind Tailscale, a VPN, firewall, or authenticated reverse proxy. Fleet
production support remains limited to the outbound-only HTTPS broker. Fleet WireGuard and AI Gate
remain preview surfaces, and the Model Intake Firecracker tier remains an explicit AMD64 Linux/KVM
host installation.
