# ShakerScan 0.8.11

ShakerScan 0.8.11 carries forward the published 0.8.9 Redis Stream route-lifecycle fix and completes
the remote-mode agent, MCP, skill, and documentation audit started in the unpublished 0.8.10
candidate.

## Fixes

- `shakerscan agent codex|claude|opencode` exports the actual host-reachable API bind and the
  browser-facing UI URL. A Tailscale-only API is no longer misreported as stopped by installed
  project commands or the Claude session hook.
- The session hook derives the persisted API bind and port when an operator launches Claude
  manually from the runtime instead of through the wrapper.
- `shakerscan mcp` routes the read-only adapter to the configured host bind and enables that
  non-loopback origin only when the wrapper loaded a non-loopback runtime configuration.
- General and Model Intake skills consistently use the runtime API base for OpenAPI and workflow
  commands; loopback examples explicitly tell remote operators to use `scanner.sh status`.
- Installed README and skill links use public URLs for engineering documents intentionally omitted
  from the minimal curl runtime.
- Architecture and functionality references describe the current Redis Streams lease model and all
  six API background controllers instead of the retired list-pop model.

## Validation

The candidate must pass the full backend, CLI, documentation, and UI suites; generated inventory;
named release gates; dependency audits; production builds; clean/dirty upgrade smokes; independent
published-manifest verification; and literal clean installation on the control-plane and worker
VPSs. Remote acceptance additionally verifies agent environment routing, MCP startup, managed HTTPS
Fleet enrollment, exact-node parallel DAST execution, worker-loss reclaim, centralized persistence,
and a bounded Model Intake review.

## Install

After publication and stable-channel promotion:

```bash
curl -fsSL https://install.shakerscan.com | sh
```

The generated launcher pins ordinary operations to `0.8.11` unless the operator explicitly selects
another image tag.

## Supported deployment boundary

ShakerScan 0.8.11 remains a trusted-operator, self-hosted release. Localhost is the default; remote
operator access belongs behind Tailscale, a VPN, firewall, or authenticated reverse proxy. Fleet
production support remains limited to the outbound-only HTTPS broker. Fleet WireGuard and AI Gate
remain preview surfaces, and the Model Intake Firecracker tier remains an explicit AMD64 Linux/KVM
host installation.
