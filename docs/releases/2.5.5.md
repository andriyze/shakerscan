# ShakerScan 2.5.5

This release improves how a Scan binds a target name and chooses its HTTP transport, makes incomplete examination visible, and fixes several service and Hunt reliability defects.

## Target and Scan behavior

- A target entered as an apex or `www` name uses a bounded DNS fallback to its twin only when the requested name has no address record. The target identity and authorization remain attached to the selected host. (#232)
- A target entered without a scheme freezes both HTTP and HTTPS for the selected host and port. A required, metered `scan.origin_select` action probes those frozen origins, HTTPS first, and persists the chosen origin for later actions and resumed execution. Explicit schemes remain exact. (#233)
- An unexamined application cannot produce a risk grade or complete coverage. Failed origin selection retains attempted-origin evidence; redirects outside the bound origin are reported as coverage gaps. (#236)
- Runtime DNS revalidation tolerates rotating CDN answers while connections remain pinned to the admission-time address set. Forbidden rebinding answers still fail closed. (#236)

## Reliability and operator flow

- Private-network target refusals identify the deployment setting that controls admission, while infrastructure and metadata destinations remain forbidden. (#236)
- Headless crawler memory is bounded across its process tree. Memory stops keep partial output; cancellation and hard timeout stop descendants. (#236)
- Configured-AI research episodes start their autopilot, and invalid or incomplete planner configurations return actionable errors. (#236)
- Ubuntu APT mirror rewriting uses a `sed` invocation that works on GNU and BSD variants, allowing the installer tests to run on macOS as well as Linux.
- PR smoke selects relevant real-stack E2E areas for isolated changes and retains complete final-image certification. Release candidates reuse a verified exact-SHA image build when available. (#235)

## Validation

Release-candidate certification, published-version smoke, and stable-channel promotion are required before 2.5.5 is public.
