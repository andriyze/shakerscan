# ShakerScan 2.5.3

This server patch fixes managed browser login checks found during the public two-machine
acceptance of 2.5.2. The public client remains 0.7.2.

## Hunt

- `browser.login_check` now handles a protected page's redirect to the saved login URL
  and a login POST's redirect to the saved protected URL inside its pinned browser
  transport. Chromium previously followed those fulfilled redirects outside the
  interception route, causing an `anonymous_verification_incomplete` failure before
  credentials were submitted. Other redirect destinations remain blocked.
- The fix is covered by a synthetic real-Chromium login test, including JavaScript
  rendered form fields and a successful single POST.

## Validation and limits

The pre-fix behavior was reproduced in the installed 2.5.2 browser worker on EC2.
The 2.5.3 candidate still requires certification, public install smoke, and stable
promotion before this version is public.
