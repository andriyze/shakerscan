# ShakerScan 2.0.0

**Published 2026-09-03.** One deterministic Scan, one target-kind-aware Hunt runtime, and a
release pipeline that certifies exact image digests before anything moves.

## Changes

- One canonical Scan execution plan for local, broker, and parallel workers: immutable plan
  revisions, hard multi-dimensional budgets, action-level resume, and receipt-backed evidence.
- One Hunt runtime for web, API, network, and connected-device targets; the coding agent plans,
  the server executes only manifest capabilities.
- Credentials and request collections are exact-target, encrypted, metadata-only objects; scans
  and hunts carry opaque profile ids, never secrets.
- Connected Devices as a separate namespace with opt-in workers, bounded inventory, SSH posture,
  and policy controls.
- Scoring reports two independent axes: observed risk and examination strength (`risk_and_assurance/v8`).
- Legacy `scan-full`, `scan-smart`, `--type`, planner-supplied argv, and raw Hunt launch aliases
  cannot create new work. 31 research/agent/Arsenal write routes remain as a tracked
  compatibility backlog.
- CLI and MCP cover targets, findings, evidence, credentials, collections, Scan, and bounded Hunt;
  MCP separates read-only inspection from target-bound Hunt tools.

## Upgrade

- Back up first (`shakerscan backup`), then re-run the installer; see
  [`docs/upgrade-and-rollback.md`](../upgrade-and-rollback.md).
- Migrations preserve targets, scans, findings, policies, credentials, collections, evidence,
  and fleet identity. Startup fails closed on a schema or build-identity mismatch.

## Known limitations (declared debt)

- Bounded active profiles do not fund state-changing body-injection verification; SQLi/XSS
  candidates in request bodies degrade to query-only checks.
- The installed CLI wrapper cannot complete Hunt start/call in the packaged smoke stack; the same
  authority is proven server-side.
- Model Intake durable trust-anchor lifecycle is preview and outside this release's scope.
- AI Gate is preview. WireGuard fleet transport is preview; the outbound HTTPS broker is supported.
