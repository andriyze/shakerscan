# ShakerScan 0.8.12

ShakerScan 0.8.12 carries forward the published 0.8.9 Redis Stream route-lifecycle fix and the
remote-mode agent, MCP, skill, and documentation fixes from the unpublished 0.8.10 and 0.8.11
candidates. It also closes the Model Intake sandbox queue permission issue found during 0.8.11's
final whole-product audit.

## Fixes

- `shakerscan agent codex|claude|opencode` and `shakerscan mcp` use the configured host-reachable
  API bind on remote and Tailscale installations; the Claude session hook derives the same bind
  from persisted runtime configuration.
- General and Model Intake skills consistently use the runtime API/UI bases, and installed-runtime
  links for omitted engineering documents resolve to the public repository.
- Architecture and functionality references describe the current Redis Streams lease model and
  all six API background controllers.
- The Model Intake sandbox evidence queue is owned by the exact non-root identity used by the
  isolated container and is mode `0700`. Standalone, Docker Desktop, and Fleet installs no longer
  rely on a host-world-writable `0777` queue, preventing another local host account from forging or
  disrupting sandbox request/response evidence.

## Validation

The candidate must pass the full backend, CLI, documentation, and UI suites; generated inventory;
named release gates; dependency audits; production builds; clean/dirty upgrade smokes; independent
published-manifest verification; and literal clean installation on the control-plane and worker
VPSs. Remote acceptance additionally verifies agent environment routing, MCP startup, managed HTTPS
Fleet enrollment, exact-node parallel DAST execution, worker-loss reclaim, centralized persistence,
a bounded Model Intake review, and private sandbox queue ownership on the worker host.

## Install

After publication and stable-channel promotion:

```bash
curl -fsSL https://install.shakerscan.com | sh
```

The generated launcher pins ordinary operations to `0.8.12` unless the operator explicitly selects
another image tag.

## Supported deployment boundary

ShakerScan 0.8.12 remains a trusted-operator, self-hosted release. Localhost is the default; remote
operator access belongs behind Tailscale, a VPN, firewall, or authenticated reverse proxy. Fleet
production support remains limited to the outbound-only HTTPS broker. Fleet WireGuard and AI Gate
remain preview surfaces, and the Model Intake Firecracker tier remains an explicit AMD64 Linux/KVM
host installation.
