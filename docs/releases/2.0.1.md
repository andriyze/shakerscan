# ShakerScan 2.0.1

**Published 2026-09-03.** A DAST recall, scoring, and scan-result quality release on the 2.0.0 platform. No
schema, capability-authority, or installer-contract changes; upgrade in place.

## Changes

- Discovery reads the target's own API description: `web.spec_ingest` fetches and parses
  OpenAPI 3.x / Swagger 2.0, so declared body and path routes a crawl never exercises become
  candidates. Templated path segments (`/api/orders/{int}`) are tested as SQL injection sites.
- The headless browser crawl now carries the scan credential, at parity with the static crawl.
- Scoring counts a finalizer-verified finding as proven, not suspected: a proven critical no
  longer grades as if it were only suspected.
- Post-discovery verification is admitted against the budget discovery actually left, so the
  verifier and proof stages are no longer starved by held-back reservations.
- One missing response header is reported once per origin, not once per crawled URL.
- Candidate ranking demotes transport plumbing and cache-buster parameters below real inputs.
- The scan result tells one coverage story: proven findings lead, coverage gaps read in operator
  terms, the target's headers/TLS/DNS/ASN posture is shown with provenance, and the layout holds
  on narrow screens.
- Base images updated (Go 1.27.x, Node 26, Python 3.14 signer).

## Upgrade

- Re-run the installer; migrations and stored data are unchanged from 2.0.0. See
  [`docs/upgrade-and-rollback.md`](../upgrade-and-rollback.md).
