# ShakerScan 2.3.4

A maintenance release. It fixes the autonomous (configured-AI) research Hunt planner, which
could not run in any deployment. Upgrade in place from 2.3.3; 0.8.18 remains the oldest directly
certified upgrade base. No change to the deterministic proof boundary.

## Changes

### Autonomous research Hunt: the planner runs

- `api/settings_routes/router.py` never imported `importlib` at module scope, so
  `_load_research_ai_provider` raised `NameError`, the bare `except` swallowed it, and the loader
  always returned `None`. The configured-AI research planner therefore failed with "Shared AI
  provider client is unavailable" and the autopilot runner paused every episode after three
  attempts, so a self-driving research Hunt never advanced. The settings-page AI probe was
  unaffected because its own loader imports `importlib` correctly, which masked the bug. The
  loader now imports `importlib` itself.
- `scanner_tools.ai_classifier.call_ai_provider` POSTed to `AI_URL` verbatim, so a base provider
  URL (for example `https://openrouter.ai/api/v1`) reached the provider's website and returned a
  404 HTML page. The scan classification and verification paths already appended
  `/chat/completions`, which masked this for those callers. `call_ai_provider` now normalizes a
  base URL to the full chat/completions endpoint, leaving full endpoints, the OpenAI Responses
  API and Anthropic `/v1/messages` URLs unchanged.

## Upgrade

Upgrade in place from 2.3.3. No migration. The autonomous research Hunt additionally needs the
engine's AI-ops executor enabled and a model that supports strict structured outputs.
