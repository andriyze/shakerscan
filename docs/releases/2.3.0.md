# ShakerScan 2.3.0

Hunt gains a complete assisted object-authorization investigation, and hosted-workspace
capabilities land alongside it. Upgrade in place from 2.2.0; 0.8.18 is the oldest directly
certified upgrade base. No change to the deterministic proof boundary: Hunt produces
evidence-backed candidates, never verified findings, and only deterministic proof contracts
promote a finding.

## Changes

### Hunt: assisted object-authorization investigation

- A cross-principal selected-object (BOLA) investigation built on the existing `authz.verify`
  capability: propose a captured GET, review a digest-bound proposal, run a bounded four-request
  comparison, and record an explicitly unverified candidate. Results stay `inconclusive`; no
  finding is promoted and `authz.verify` is metered like any other verification.
- Composite response envelopes (an object returned beside a related one) are examined by resolving
  the requested object inside the envelope, so authenticated APIs that wrap their objects are
  supported without target-specific knowledge.
- Durable candidate history with fingerprint de-duplication and serialized materialization; the
  read path reports the recorded candidate without creating one, so a resumed session sees prior
  leads rather than concluding none exist.
- A read-only investigation review panel over the existing knowledge query, an offline
  investigation scorer that requires charge provenance, and review metrics kept separate from proof.
- Investigation memory records access separately from authorization, snapshots experiment
  conditions immutably, derives current versus historical outcomes from the latest attempt, and
  keeps conflicting ownership claims explicit.

### Hosted capabilities

- Hosted-workspace HTTPS/MCP transport, managed scheduling, public retry/receipt recovery,
  queue-handoff safety, CLI/MCP support, and a workspace-aware UI. Hosted Hunt experiment-key wiring
  is intentionally deferred and is not an enabled capability in this release.

### DAST and release hygiene

- One failing verifier candidate no longer crashes the whole batch, and verifier attempts run the
  cheapest cost class first.
- The Juice Shop authenticated recall quality bar holds at its shipped level with verified SQLi and
  five declared gaps; regression gates still fail a new miss, a recall drop, or a new false positive.

## Upgrade

Upgrade in place from 2.2.0. The stable installer channel advances only after publication and public
smoke. No capability-authority change; no destructive migration.
