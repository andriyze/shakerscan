# ShakerScan 0.8.15

ShakerScan 0.8.15 is a Fleet initialization and release-validation reliability patch over the
published 0.8.13 release. It carries forward the complete scanner, API, UI, Model Intake,
agent/MCP routing, documentation, and private sandbox queue fixes.

## Fixes

- Managed broker Fleet initialization now treats the bundled MinIO bucket initializer as part of
  readiness. The control plane retries the real artifact PUT/GET/DELETE health probe for up to 120
  seconds instead of rolling a valid conversion back when the API becomes healthy a moment before
  the bucket exists.
- The same bounded retry applies to operator-configured external S3 storage and still fails closed
  when the artifact plane never becomes writable.
- A regression covers transient HTTP failure, a structured not-ready response, and eventual
  successful artifact persistence.
- Stable-channel runtime validation now derives the active version from `install/STABLE_VERSION`
  and requires a matching published release-ledger row. It no longer hardcodes an old release and
  blockades every legitimate stable promotion.

## Validation

The frozen candidate must pass the full backend, CLI, documentation, and UI suites; generated
inventory; named release gates; dependency audits; production builds; clean/dirty upgrade smokes;
independent published-manifest verification; and literal clean installation on the control-plane
and worker VPSs. Remote acceptance additionally verifies managed HTTPS Fleet enrollment,
exact-node parallel DAST execution, worker-loss reclaim, centralized persistence, a bounded Model
Intake review, agent and MCP remote routing, and private sandbox queue ownership.

## Install

After publication and stable-channel promotion:

```bash
curl -fsSL https://install.shakerscan.com | sh
```

The generated launcher pins ordinary operations to `0.8.15` unless the operator explicitly
selects another image tag.

## Supported deployment boundary

ShakerScan 0.8.15 remains a trusted-operator, self-hosted release. Localhost is the default; remote
operator access belongs behind Tailscale, a VPN, firewall, or authenticated reverse proxy. Fleet
production support remains limited to the outbound-only HTTPS broker. Fleet WireGuard and AI Gate
remain preview surfaces, and the Model Intake Firecracker tier remains an explicit AMD64 Linux/KVM
host installation.
