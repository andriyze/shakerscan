# ShakerScan 0.7.0

ShakerScan 0.7.0 is a major scanner-engine release for trusted operators running locally or on a
private VPS. It is not a hosted SaaS release: it does not add ShakerScan login, users, roles, tenant
isolation, or comprehensive evidence-secret masking. Keep remote deployments behind Tailscale, a
VPN, firewall, or an authenticated reverse proxy, and treat scan results and backups as sensitive.

## Highlights

- Stronger deterministic proof boundaries for SQL injection, XSS, authenticated access control,
  BOLA/IDOR, mass assignment, JWT checks, finding severity, and attack-chain presentation.
- Registry-authoritative detector dispatch and honest completed, skipped, blocked, cancelled,
  failed, and partial execution receipts.
- Improved authenticated API discovery and distinct-principal BOLA controls, including proof that
  both target identities were accepted before a verified cross-user result can pass.
- Bounded cancellation, request, time, endpoint, payload, redirect, and same-origin enforcement for
  active scanner work.
- Fail-closed database migrations, a real upgrade smoke test from 0.5.7, and documented backup,
  upgrade, verification, and rollback procedures.
- Reproducible scanner inputs: locked Python dependencies, immutable scanner assets/templates,
  pinned base images, Next.js 16.2.10, and Node.js 24 LTS.
- Expanded local workflows across Web DAST, Deep Hunt, Continuous ASM, evidence, findings,
  Interactive Testing, AI Gate, and Model Intake. AI Gate and Model Intake remain preview surfaces
  for this release.
- Deep Hunt works after a standard first-time install with the current coding agent as its keyless
  planner. Target authorization, expiring approvals, same-origin enforcement, and hard budgets remain
  mandatory; administrators can set `AI_OPS_ROUTER_EXECUTE_ENABLED=false` as a global kill switch.

## Upgrade

Back up first, then follow [the upgrade and rollback runbook](../upgrade-and-rollback.md). A failed
required migration now stops startup instead of continuing with a partially repaired schema.
