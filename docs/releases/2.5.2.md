# ShakerScan 2.5.2

This patch fixes two defects found in the clean, two-machine test of the 2.5.1 server and
0.7.1 client. Client 0.7.2 is released from the same source revision.

## Hunt

- `auth.session.establish` now rejects an incompatible saved credential profile before
  reserving a Hunt action. A profile without session-establishment permission, or a
  non-interactive Basic-auth profile, no longer leaves an action running until the stale
  reservation sweeper settles it. The caller can correct the selection and finish the Hunt
  immediately. (#208)

## Client 0.7.2

- For a direct LAN connection to a server API on port 8080, `shakerscan scan --json` now
  reports the scan page on the server UI's port 3000. Connections through a reverse proxy
  retain their configured origin. (#208)

## Validation and limits

The fixes have behavioral regression tests for Hunt admission and client URL generation.
PR #208 passed the Python, Chromium, acceptance, and full-stack smoke gates. The exact
2.5.2 candidate still requires release certification, published-version smoke, and
stable-channel promotion before this version is public.
