How is this domain set up?

DNS, email, HTTP and TLS facts for any public domain or IP address, measured by the same engine as shakerscan check. No account, no scores: just what was observed and how.

Options

A DKIM key can only be looked up by its selector, and selectors are never guessed. Leave empty to skip.

To test CORS on a specific path, enter a full URL such as https://example.com/api; the path is probed with a fixed foreign Origin.

·

Each observation is a measured fact with the scope of the probe that produced it. The service makes no pass/fail judgment; the Review list is this page’s short reading of a few clearly risky values, the same as the command line shows.

From a terminal: pipx install shakerscan then shakerscan check example.com. Results saved with --json open here too, without leaving your device.
